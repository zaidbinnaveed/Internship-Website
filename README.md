# Shoply storefront prototype

A multi-page, frontend-only commerce prototype built during internship practice. The repository explores responsive product discovery, category and search views, product details, cart controls, account forms, checkout presentation, and lightweight client-side validation.

## Scope

Shoply is a static UI prototype. Product data and imagery are illustrative, and the project does not include a backend, database, authentication service, inventory system, or payment processing.

## Pages

- Home and category discovery
- Search results
- Product detail
- Cart and checkout
- Account interface

## Stack

- Semantic HTML
- CSS
- Vanilla JavaScript

## Run locally

Open `index.html` in a browser. No package installation or build step is required.

## Interaction notes

`main.js` provides gallery switching, quantity controls, mobile-navigation hooks, and basic required-field validation. These interactions demonstrate the user flow; they do not persist data or submit real transactions.
